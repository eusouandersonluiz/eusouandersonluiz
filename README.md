### 💼 O que eu faço

**GTM Engineering** — Transformo processo comercial e de marketing em sistema: tracking, ingestão da Meta Ads API, dashboards de faturamento e NPS, e automações que fecham o ciclo entre campanha, lead e receita. Camada de dados em Python com pandas, numpy e Plotly quando a pergunta é analítica.

**Agentes & Automação** — Squads de agentes em LangGraph com checkpoint em Postgres, servidores MCP próprios e observabilidade via Langfuse. Integração com WhatsApp, CRM, ClickUp e Meta Ads. Desenvolvimento agêntico é prática diária aqui: 27 dos meus repositórios carregam um `CLAUDE.md` versionado.

**Produto & Full Stack** — SaaS e ferramentas internas em TypeScript com React, Next.js, Vite e Astro. Interface sobre shadcn/ui e Radix, validação com Zod, formulários com React Hook Form, gráficos com Recharts. Persistência em PostgreSQL e Supabase, ORM com Prisma ou Drizzle, cache em Redis.

**Infra & Entrega** — Cloudflare Workers e D1 como plataforma padrão, Docker onde faz sentido, GitHub Actions para CI e deploy. Menos servidor para cuidar, mais produto no ar.

**Liderança Técnica** — Arquitetura, padrões de código e decisão de stack para times que precisam entregar rápido sem virar dívida técnica.
